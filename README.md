# 相関図自動生成サービス

> 作品名やキャラクター名を入力するだけで、AIが人物の関係図を自動生成します。

---

## こんな使い方に

- アニメ・漫画・小説の登場人物の関係を整理したい
- ドラマや映画を見ながら「誰と誰がどんな関係？」を可視化したい
- オリジナルキャラクターの相関図を素早く作りたい
- 手動で人物とエッジを入力して自分だけの関係図を作りたい

---

## 使い方

### AI生成
上部の入力欄にキャラクター名や作品名を入力して **Enter** を押すと、AIが自動で人物と関係をマップ化します。

### 手動入力
左側パネルで人物（ノード）と関係（エッジ）をテキスト記法で直接入力できます。

```
# 人物
名前 | 重み1-12 | 説明

# 関係
A - B | ラベル
```

### JSON入出力
「JSON読み込み」「JSON書出し」ボタンで保存・再利用が可能です。

---

## 画面の見方

| 要素 | 意味 |
|------|------|
| 暖色系の線 | 友好的な関係（友人・家族・仲間） |
| 寒色系の点線 | 敵対的な関係（敵・ライバル・対立） |
| グレーの線 | 中立的な関係（知人・同級生） |
| 線の太さ | 関係の強さ（太いほど強い） |

レイアウトは **ネットワーク（力学配置）** と **樹形図** を切り替えられます。

---

## 技術スタック

| 項目 | 内容 |
|------|------|
| フレームワーク | React + Vite |
| グラフ描画 | Apache ECharts（echarts-for-react core版） |
| AI生成 | OpenAI API |

---

## セットアップ

```bash
npm i
npm run dev
```

ブラウザで `http://localhost:5173` を開きます。

---

## 備考

- `echarts-for-react` は core 版を使用するため、`echarts/core` から必要モジュールを登録しています
- `createPathProxy is not a function` エラーが出る場合は ECharts とラッパのバージョン不整合が原因です。本プロジェクトの依存バージョンに合わせてください
- 画面上部の「自己テスト」でパーサとオプション生成の最低限のチェックが実行できます
